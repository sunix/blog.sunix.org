✨ Improved Code Block Styling

Key Improvements

  • Less rounded corners (0.5rem instead of 2xl) - no more cut-off code in corners
  • Solid dark background instead of gradient - better readability
  • Subtle border and shadow - professional look without distraction
  • Proper padding - comfortable spacing around code
  • Inline code styling - distinct from code blocks with light background

Example: JavaScript Function

Here's how inline code looks: const myVar = 42;

// Fetch data from API async function fetchUserData(userId) { try { const response = await fetch(`/api/users/${userId}`); const data = await response.json(); return data; } catch (error) { console.error('Error fetching user:', error); throw error; } }

Example: Long Code Block

Notice how the corners don't cut off the code:

// Complex data processing function with long lines function processComplexData(data, options = {}) { const { threshold = 0.5, normalize = true, verbose = false } = options; return data .filter(item => item.value > threshold) .map(item => ({ ...item, processed: true, timestamp: new Date().toISOString(), normalizedValue: normalize ? item.value / 100 : item.value })) .sort((a, b) => b.normalizedValue - a.normalizedValue); }

Example: Java Code

public class UserService { private final UserRepository repository; public UserService(UserRepository repository) { this.repository = repository; } public User getUserById(Long id) { return repository.findById(id) .orElseThrow(() -> new UserNotFoundException("User not found")); } }
